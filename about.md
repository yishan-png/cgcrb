This is a working demonstration of a bilingual reference website. **Every guideline passage is placeholder text, not approved cataloging guidance.** No institutional endorsement or publication authority is implied.

本網站為中英雙語參考指南的示例。**所有指南文字均為佔位內容，並非正式編目規則。**

## Four levels of information / 四層結構

1. **Chapter / 章:** for example, 1 General principles.
2. **Section / 節:** for example, 1.1 Scope.
3. **Rule / 規則:** for example, 1.1.1 Types of material.
4. **Subrule / 子規則:** for example, 1.1.1.1 Single-volume and multi-volume material.

## Reading and navigation / 閱讀與導覽

Chinese appears on the left and English on the right on larger screens. On smaller screens, each Chinese passage is followed by its English counterpart. The two versions stay paired by rule rather than by individual lines.

在較大的螢幕上，中文位於左欄，英文位於右欄。在較小的螢幕上，每段中文之後緊接對應的英文，並以規則為單位保持配對。

- Select a rule number to get its permanent link.
- Use the chapter sidebar and section links to move through the text.
- [Search]({{ '/search/' | relative_url }}) for Chinese phrases, English terms, or rule numbers.
- Use the chapter's print button or your browser's Print command for a simplified reading layout.

## Replacing the placeholders / 置換示例文字

The final Chinese and English source files will be preserved. Web-ready Markdown derivatives will replace the sample rule pairs after their structure is inspected. See the project README for local development instructions.
